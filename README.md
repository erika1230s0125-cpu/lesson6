# 👋 自己紹介ページ

HTML と CSS で作った、シンプルな自己紹介ページです。

## 📖 概要

プログラミング学習の一環として作成した、1枚完結の自己紹介カードです。

- 🙋 **プロフィール**：名前とひとこと紹介
- 💙 **趣味**：推し活・カフェ巡り・旅行
- 📊 **スキル**：HTML/CSS・JavaScript・AI活用をバーで表示

## ✨ 見どころ

| 機能 | 内容 |
| --- | --- |
| フェードイン | ページを開くと、カードが下からふわっと表示されます |
| ホバー効果 | 趣味の項目にマウスを乗せると色が変わります |
| スキルバー | スキルのバーが 0% から伸びるアニメーション付きです |
| レスポンシブ | スマホでも見やすいサイズで表示されます |
